    Đưa mô hình Revit (.rvt) vào trang này

    File .rvt là định dạng nhị phân đóng của Autodesk: chỉ Revit hoặc dịch vụ Autodesk Platform Services đọc được, trình duyệt không thể phân tích trực tiếp. Đường đi chuẩn là xuất IFC rồi nạp vào đây (trang đọc IFC 2x3, IFC4 và IFC 4x3 bằng bộ phân tích riêng, không cần cài gì).

    1. Trong Revit: File → Export → IFC, chọn setup IFC4 Reference View hoặc IFC 2x3 Coordination View 2.0; trong tab Property Sets bật Export base quantities để có khối lượng. Với mô hình cầu nên chọn IFC4x3 nếu bản Revit hỗ trợ.
    2. Hoặc qua revit-mcp: khi Revit đang mở mô hình, nhờ Claude chạy doc.Export(thư_mục, tên, new IFCExportOptions()) qua công cụ send_code_to_revit; file IFC được ghi ra đĩa và nạp vào đây.
    3. Nạp file .ifc bằng nút Nạp JSON / IFC hoặc kéo-thả vào khung 3D. Mô hình được tự đưa về gốc toạ độ; chỉnh Căn chỉnh trong bảng thuộc tính nếu cần đặt chồng lên cấu kiện sinh ra.

    Hình học IFC được dựng: đùn tiết diện (chữ nhật, tròn, I, T, U, L, hình thang, đa giác bất kỳ có lỗ), xoay tiết diện, B-rep mặt phẳng, lưới tam giác/đa giác (IFC4), mapped item (family instance), cắt bằng half-space, ống quét theo đường, khối cơ bản. Chưa dựng: NURBS/advanced brep, quét theo mặt cong, boolean giữa hai khối đặc; các mục này được đếm và báo trong thuộc tính mô hình.
