# TessellatedShapeBuilder Class

[Nguồn gốc](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/a144b0e3-c997-eac1-5c00-51c56d9e66f2.htm) · Autodesk Revit API Main Reference, 26.4.0.0 · Năm: 2026.

## Nội dung rút ra

Tài liệu Revit mô tả lớp dựng hình từ các mặt liên thông, với mục tiêu hình học và chế độ dự phòng được khai báo. Kết quả có thể phục vụ đưa hình tính toán vào mô hình Revit qua DirectShape. Đây là tuyến kỹ thuật phù hợp cho mesh hữu cơ, nhưng cần kiểm tra kiểu kết quả thật sự và lỗi dựng hình. Việc có đối tượng Revit không tự biến nó thành Family tham số.

- Phải khai báo và kiểm tra Target/Fallback của bộ dựng.
- Kết quả mesh cần phân biệt với solid mong muốn.

## Giới hạn

- Chưa thực thi API trong phiên Revit thực.
- Tài liệu API không chứng minh hình học đáp ứng tiêu chuẩn thiết kế.
- Không tự kiểm giao nhau giữa các face sets; đảo hướng mặt không tạo void theo Remarks của lớp.
