# fib Model Code for Concrete Structures (2020)

[Nguồn gốc](https://shop.fib-international.org/publications/model-code-supporting-documents/984-fib-model-code-for-concrete-structures-2020) · International Federation for Structural Concrete (fib) · Năm: 2023.

**Mức đọc:** Chỉ thư mục/chỉ mục. **Truy cập:** CATALOG_ONLY.

**Vị trí đã đọc:** Trang sản phẩm; mục lục công khai và trang bản quyền.

## Nội dung rút ra

Hồ sơ xuất bản và mục lục công khai cho thấy Model Code tổ chức kiến thức theo tính năng, quản lý vòng đời, chất lượng, thông tin, thi công và bảo tồn. Đợt này ghi nhận cấu trúc tham khảo; chưa đọc phần tính toán của sách có bản quyền.

- Tên Model Code 2020 khác năm bản quyền 2023; trang bản quyền được xem ghi Version 1.2 [2024].

## Giới hạn

- Model Code không tự động là quy chuẩn áp dụng tại một quốc gia.
- Chỉ đọc thư mục và mục lục công khai.
